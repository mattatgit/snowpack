# Snow model

The first snow model will be a transparent, parameterised model rather than a full multilayer snow-physics system.

Initial components:

- snowfall accumulation;
- simple density/settlement;
- temperature-driven change;
- solar exposure;
- wind erosion/deposition;
- uncertainty/provenance.

Once the historical POC is working, compare its behaviour with an established model such as FSM2 or SNOWPACK/Alpine3D.
