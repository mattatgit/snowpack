# 3D viewer

The viewer is intentionally deferred until the terrain/data pipeline produces real output.

Likely first implementation:

- Three.js;
- rotatable/zoomable terrain;
- time slider;
- layer switcher;
- click/tap cell inspection;
- visually distinct modelled vs observed information.

Initial layers:

- terrain;
- slope;
- snow depth;
- new snow;
- wind redistribution;
- solar exposure;
- observations;
- confidence.
